# Gestão do trabalho

O calendário adotado segue os enunciados das atividades: M1/Sprint 1 de 20/10 a 02/11/2026; M2/Sprint 2 de 03/11 a 23/11/2026.

As pastas de turmas, planos de ensino e [tutorial de GitHub Projects](TUTORIAL_GITHUB_PROJECTS.md) são referências de apoio. Suas cópias históricas podem conter calendários de outras turmas; servem como referência de configuração.

Os arquivos `issues_github.json` oferecem definições de trabalho para importação. Antes de executar scripts, confira os issues existentes para evitar duplicação. A versão corrente das definições usa o domínio ENADE e separa documentação concluível de atividades que exigem participação externa.

Uma tarefa documental é encerrada quando o artefato correspondente foi publicado e conferido.
