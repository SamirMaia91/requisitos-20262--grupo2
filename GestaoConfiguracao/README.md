# Gestão do trabalho

O planejamento vigente do Grupo 2 está no [Plano de entregas ENADE](../Requisitos/Artefatos/SistemaApoioENADE/PlanoDeEntregas.md). O calendário adotado segue os TXT fornecidos: M1/Sprint 1 de 20/10 a 02/11/2026; M2/Sprint 2 de 03/11 a 23/11/2026.

As pastas de turmas, planos de ensino e [tutorial de GitHub Projects](TUTORIAL_GITHUB_PROJECTS.md) são referências de apoio. Suas cópias históricas podem conter calendários de outras turmas; não são evidência de entrevistas, validações ou tarefas executadas.

Os arquivos `issues_github.json` oferecem definições de trabalho para importação. Antes de executar scripts, confira os issues existentes para evitar duplicação. A versão corrente das definições usa o domínio ENADE e separa documentação concluível de atividades que exigem participação externa.

Fechar uma tarefa documental significa publicar e verificar o artefato. Não significa aprovação do professor ou de usuários. Mantenha entrevistas, validação e comprovantes em aberto enquanto não houver evidência.
