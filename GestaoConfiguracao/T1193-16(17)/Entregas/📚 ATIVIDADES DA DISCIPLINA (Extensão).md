


# 📚 ATIVIDADES DA DISCIPLINA (Extensão)

### 🔧 Uso do GitHub

Cada grupo deverá:

1. Criar um repositório no GitHub
2. Nomear no padrão: requisitos-2026-<nome-do-projeto></nome>-grupoX
3. Adicionar o professor como colaborador:  usuário:marcelobezerra-dotcom
4. Manter o repositório atualizado com: Issues (fornecidas pela disciplina), Commits organizados por sprint e Entregáveis versionados (PDF, UML, SRS, protótipos)
5. Use o repositório como guia: [github.com/marcelobezerra-dotcom/Lapis-unifor](https://github.com/marcelobezerra-dotcom/Lapis-unifor)
6. Exemplo prático do projeto Feira Livre: [github.com/marcelobezerra-dotcom/requisitos-projeto-feira-livre-2026-01](https://github.com/marcelobezerra-dotcom/requisitos-projeto-feira-livre-2026-01)

### ⚠️ Regra obrigatória

* O link do repositório deve ser enviado em **todas as atividades**
* O professor deve ter acesso garantido ao repositório
* A ausência de acesso ao usuário **marcelobezerra-dotcom** poderá implicar **desconto de até 50% da nota**
