# Glossário

| Termo | Definição neste projeto |
| --- | --- |
| ENADE | Exame Nacional de Desempenho dos Estudantes; a plataforma apenas apoia a preparação. |
| Componente | Formação geral ou componente específico, conforme identificação da prova. |
| Tema | Classificação pedagógica atribuída durante a curadoria. |
| Questão publicada | Item objetivo conferido, com origem, gabarito e comentário revisado. |
| Tentativa | Execução de prática ou simulado de um estudante. |
| Fotografia da tentativa | Cópia da versão das questões e gabaritos utilizada no início, preservada no resultado. |
| Omissão | Questão da tentativa sem resposta registrada no encerramento. |
| Percentual de acertos | Indicador de estudo calculado segundo RN-07; não é a nota oficial do exame. |
| SRS | Especificação de Requisitos de Software. |
| Validação | Confirmação de adequação pelos interessados; não se confunde com verificação técnica. |
| Protótipo | Interface executável de alta fidelidade, com acesso público e dados locais ao navegador, para avaliar navegação e regras com limites documentados. |
