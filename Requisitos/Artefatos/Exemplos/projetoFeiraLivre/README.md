# Projeto Feira Livre

Esta pasta reúne artefatos de exemplo para a demanda de gestão das feiras livres de Fortaleza. Os documentos são material didático e de trabalho: a visão não representa aprovação formal da Prefeitura, e regras, responsabilidades e referências legais ainda precisam ser validadas pelos responsáveis.

## Artefatos principais

- [Visão da Demanda LAPIS v2.1](exemplo-feira-livre-visao-LAPIS-v2.1.md): contexto, escopo, necessidades, funcionalidades, atores, casos de uso, condições e questões em aberto.
- [Diagrama de casos de uso (SVG)](diagrama-casos-de-uso.svg): imagem vetorial usada para visualizar os atores e casos de uso.
- [Diagrama de casos de uso (PNG)](diagrama-casos-de-uso.png): versão rasterizada do diagrama.
- [Fonte PlantUML do diagrama](diagrama-casos-de-uso.puml): código editável para atualizar ou gerar novamente o diagrama.
- [Visão anterior](exemplo-feira-livre-visao.md): versão anterior do documento de visão.
- [Proposta da Feira Livre](PropostaFeiraLivre.md): solicitação que fundamenta parte dos requisitos do exemplo.
- [Glossário](glossario-feira-livre.md): termos do domínio.
